A fast, accessible block theme for local service businesses.

== Description ==

Keystone is a block theme for clinics, trades, studios and shops. It uses system fonts and no theme JavaScript,
so pages are about 30% lighter than Twenty Twenty-Five on the same content. It includes patterns for a hero,
services, pricing, testimonials, FAQs and contact details, and three style variations (Forest, Terracotta and
Midnight). Every text colour pairing in every variation meets WCAG AA contrast.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New Theme.
2. Click Upload Theme, choose keystone.zip and click Install Now.
3. Activate the theme, then open Appearance > Editor to choose a style and edit templates.

== Frequently Asked Questions ==

= How do I build a home page? =

Create a page, open the block inserter, choose Patterns > Keystone sections and add the sections you need.

= Why are there no Google Fonts? =

System fonts render instantly and cost nothing to download. Install the Font Library fonts of your choice from the
Site Editor if you prefer a different typeface.
